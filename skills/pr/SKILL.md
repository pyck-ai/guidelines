# Pull request guideline

The guideline is [pull-requests.md](pull-requests.md) in this directory. Read it in full before you start. Without a local copy, read <https://raw.githubusercontent.com/pyck-ai/guidelines/main/docs/pull-requests.md>.

## Checklist

- The description serves the review; anything that must outlive it is in a commit.
- The description follows the guideline's "Description structure".
- The summary is written as the guideline's "Summary" section describes.
- No em or en dashes.
- Fill the org template as is ([PR template](https://raw.githubusercontent.com/pyck-ai/.github/main/.github/PULL_REQUEST_TEMPLATE.md)); never restate its fields.
