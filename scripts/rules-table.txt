# Source of the table in AGENTS.md ("Guidelines, loaded on demand"), read by
# scripts/generate-table.sh. One row per line, three fields separated by " | ":
#
#   skills | files | when
#
#   skills  skill names, comma-separated, in display order; `-` for none. Each
#           skill of a row without its own files needs a skills/<name>/SKILL.md.
#   files   `auto`: the docs of those skills, from MAP in scripts/generate-skills.sh.
#           Anything else is the cell verbatim (for rows whose skills or files live
#           outside this repository); repo paths in backticks must exist.
#   when    the text of the "When you" column, verbatim; this is the only part of the
#           table that is written by hand.
#
# Row order is table order. A new doc with a skill needs its row here and its pair
# in MAP; then run `task generate`.
#
# skip: docs that are no guideline and so get no row.
